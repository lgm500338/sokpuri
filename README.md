# 속풀이 해방구 (SOKPURI)
> **스트레스 타격 샌드박스 & 감정 소각장 | Stress Release Sandbox & Rage Incinerator**

일상에서 쌓인 억울함, 분노, 스트레스를 시원하게 날려버릴 수 있는 인터랙티브 아케이드 웹 애플리케이션입니다.

---

## 주요 기능

1. **3D 밀실 타격 샌드박스**
   - 3D 골판지/나무 감옥 밀실 배경
   - 3가지 타깃 캐릭터 선택: 솜뭉치 곰, 뜨개 토끼, 충돌 테스트 더미
   - 타격 반응 물리 엔진: 래그돌 튕김, 반동, 대미지 크랙 및 멍 자국

2. **측면 거치 실시간 조준 총기 & 무기 도감**
   - 가로형 와이드스크린 최적화 좌/우 측면 무기 거치
   - 실시간 조준선, 총구 화염(Muzzle Flash), 반동, 탄피 배출 애니메이션
   - 돌격소총(AK-47), 바주카, 개틀링건, 샷건, 플라즈마 레이저, 냉동총, 철퇴, 전기톱 등 14종 이상의 다채로운 무기

3. **유리 수조 감전 실험실 모드**
   - 상단 3개 파이프 수조 침수 및 배수
   - 피복 벗겨진 고압 전선 드래그 수중 감전
   - 양손 사슬 매달기 및 전면 빨간 레버 / 화염 분사 장치

4. **100% 완전 익명 감정 쓰레기통 (불태우기 & 파쇄기)**
   - 누구에게도 말 못 한 분노와 스트레스를 자유롭게 작성
   - 실시간 불태우기 소각 연출 및 20가닥 파쇄기 연출
   - 서버나 로컬 스토리지에 어떤 데이터도 남기지 않는 완전 휘발성 보안 설계

5. **글로벌 지원 & 편의 기능**
   - 한국어 / English 완전 이중 언어(KR/EN) 지원
   - 가로 화면 자동 회전 감지 모드
   - 효과음 On/Off 토글

## 시작하기 (Getting Started)

### 사전 요구 사항
- Node.js 18 이상
- npm 9 이상

### 설치 (Install)
```bash
npm install
```

### 개발 서버 실행 (Development)
```bash
npm run dev
```
브라우저에서 `http://localhost:3000`으로 접속합니다.

### 프로덕션 빌드 (Build)
```bash
npm run build
```
빌드 산출물은 `dist/` 폴더에 생성됩니다.

### 빌드 결과 미리보기 (Preview)
```bash
npm run preview
```
