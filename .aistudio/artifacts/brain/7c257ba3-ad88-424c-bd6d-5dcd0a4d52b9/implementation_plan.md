# 속풀이 해방구 — 야외 도망 모드(60% 축소) · 총기 사격 시스템 · 유리 수조 모드 분리 계획안

## 1. 기본 시작 모드 전환 & 유리 수조 실험실 버튼 배치
- **기본 시작 화면 (`isSubmerged = false`)**:
  - 처음 접속하면 유리 수조가 없는 **탁 트인 가로 경기장(기본 타격·사격 모드)**으로 시작합니다.
- **유리 수조 실험실 전환 버튼 (상단 바 + 무기 서랍 양쪽 배치)**:
  - 사용자가 원할 때 언제든 스트레스 해소 방식의 하나로 켤 수 있도록 **상단 미니멀 바(`🌊 수조 감전실`)**와 **우측 무기·메뉴 서랍 상단 배너** 양쪽 모두에 전환 버튼을 배치합니다.
  - 수조 모드를 켜면 기존에 맞춘 스크린샷 스타일(유리 수조 + 천장 파이프 3개 + 드래그 컬러 전선 + 사슬 레버 & 불 버튼)과 수조 전용 인형 크기(100% 비율)가 그대로 등장합니다.

## 2. 일반 경기장 인형 60% 축소 & 도망·점프 회피 물리 강화
- **인형 크기 60% 축소 (수조 밖 일반 모드 전용)**:
  - 수조 밖에서는 인형 크기를 기존의 **60% 비율(`scale(0.6)`)**로 작고 날렵하게 줄여, 넓은 가로 공간을 실제로 뛰어다니는 느낌과 조준해서 맞히는 몰입감을 높입니다.
- **불규칙 방향 전환 & 폴짝 점프 회피**:
  - 인형이 가로 화면 좌우(14% ~ 86%)를 빠르게 달릴 뿐만 아니라, 갑자기 방향을 꺾거나 위로 **폴짝 점프(`jumpOffsetY`)**하며 총알과 무기를 피하려고 발버둥 칩니다.
  - 총기 사격 시 조준선(클릭/터치 지점)과 실제 작아진 인형의 위치 거리를 판정하여, **정확히 명중했을 때(Headshot / 정타)**와 **스쳤을 때 / 빗나갔을 때(바닥 탄흔 생성)**의 타격감 차이를 뚜렷하게 만듭니다.

## 3. 신규 『총기·중화기 (사격 무기)』 카테고리 6종 추가
우측 무기 서랍에 **🎯 총기·사격** 탭을 신설하고, 선택하신 4가지 스타일의 총기들을 모두 포함합니다:
1. **연사 기관총 (`🔫 개틀링 기관총`)**:
   - 화면을 **누르고 있는 동안(Pointer Hold)** 마우스/손가락 위치를 따라 `따다다다당!` 고속 연사 탄환과 총구 화염(Muzzle Flash), 탄피 배출 연출이 연속으로 나갑니다.
2. **전술 돌격소총 (`🔫 고속 돌격소총`)**:
   - 빠른 3점사/연사 사격으로 도망치는 인형을 추격하며 쏘기 좋은 밸런스형 총기입니다.
3. **더블배럴 샷건 (`💥 산탄 샷건`)**:
   - 한 번 쏠 때 여러 발의 산탄이 넓게 퍼져 나가며, 조금만 스쳐도 인형을 반대편 벽까지 강하게 날려버립니다.
4. **초강력 바주카포 (`🚀 바주카포`)**:
   - 거대한 폭발 화염과 화면 흔들림을 일으키며 인형을 공중으로 붕 띄워 날려버립니다.
5. **고출력 레이저 저격총 (`🎯 레이저 저격총`)**:
   - 화면을 가로지르는 붉은 레이저 빔이 즉시 관통하며, 정타 명중 시 치명타(CRITICAL) 충격파와 그을음을 남깁니다.
6. **급속 냉동·페인트총 (`❄️ 급속 냉동총` / `🎨 형광 페인트총`)**:
   - **급속 냉동총**: 명중 시 인형을 잠시 **얼음덩어리로 꽁꽁 얼려(`isFrozen`)** 도망치지 못하게 발을 묶어두고 마음껏 집중 사격할 수 있게 합니다.
   - **형광 페인트총**: 알록달록한 물감 탄환을 연속 발사해 인형을 온통 물감 범벅으로 만듭니다.

## 4. 사격 전용 시각·청각 타격감 (Web Audio API & 시각 이펙트)
- **사격 이펙트**: 총기 장착 시 커서가 **조준경(크로스헤어)** 모양으로 바뀌며, 사격 지점에 총구 섬광(Muzzle Flash), 탄도 궤적(Tracer Line), 탄흔(Bullet Hole), 화염/얼음 파편이 생성됩니다.
- **실시간 사운드**: 기관총 연사음(`machine_gun`), 샷건/바주카 폭발음(`shotgun_blast`), 레이저 관통음(`laser_zap`), 얼음 결빙음(`freeze_blast`)을 Web Audio API로 합성합니다.
